# Data Range

The testcase generator and heuristic are written for the following upper bounds:

| Parameter | Upper bound |
| --- | ---: |
| Number of stations | 100 |
| Number of cars | 1,000 |
| Number of car levels | 10 |
| Number of orders | 10,000 |
| Planning horizon | 100 days |
| Total moving time budget | 1,000,000 minutes |

Use `generate_testcases.py` to create instances inside this range.
